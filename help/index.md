# KiCad SpecGen Help

KiCad SpecGen generates specification documents from KiCad design files,
jobset outputs, and Jinja2 templates.

## Workflow

1. **Setup** — Run `python setup.py` to configure your environment.
2. **Project** — Open or create a SpecGen project linked to a KiCad project.
3. **Jobset** — Select a `.kicad_jobset` file and run export destinations.
4. **Report** — Assemble a PDF report from jobset outputs and Markdown templates.
5. **Fabrication** — Build a fabrication ZIP package for manufacture.
